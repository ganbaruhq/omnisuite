Publish the class recipes the React components now share with the workspace's Effect UI components,
as framework-free modules under `@omnisuite/ui/lib/recipes/*`: `avatar`, `badge`, `breadcrumb`,
`button-group`, `card`, `combobox`, `drawer`, `dropdown-menu`, `empty`, `input-group`, `input-otp`,
`kbd`, `layer-card`, `page`, `popover`, `radio-group`, `separator`, `sheet`, `sidebar`, `skeleton`,
`slider`, `status-dot`, `tag`, `toggle-group`, `toggle` and `toolbar`. `sidebar` also exports the
sidebar's sizes, timing, easing and mobile breakpoint (`sidebarDefaultWidthPx`, `sidebarWidthMobile`,
`sidebarWidthIcon`, `sidebarAnimationDuration`, `sidebarEasing`, `sidebarMobileBreakpointPx`,
`sidebarMobileQuery`). The React components render the same classes as before.
